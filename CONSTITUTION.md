## К-01
Код не пишется до DIRECTION.md, принятого на G1.

Проверка: V-01, V-07 · метод: валидатор

## К-02
Каждая ключевая секция сайта имеет строку «решение → источник» в SOURCES.md.

Проверка: V-02, V-03 · метод: валидатор

## К-03
Оси SEED отражены в DIRECTION; два проекта подряд с совпавшими осями запрещены.

Проверка: V-07, V-09 · метод: валидатор

## К-04
Каждый визуальный приём имеет источник в references/ или skills/; приём без источника — слоп.

Проверка: V-10 + вердикт · метод: валидатор + арт-директор

## К-05
Easing — только из motion/easing-curves.json; браузерные дефолты запрещены.

Проверка: V-06 · метод: валидатор

## К-06
1–3 motion-рецепта на страницу; конфликты из dont_combine_with не допускаются.

Проверка: V-05 · метод: валидатор

## К-07
Шрифты — только из assets/fonts/PAIRS.md, пара display + body с ролями.

Проверка: Q-06 · метод: валидатор + арт-директор

## К-08
Минимум одна текстура из assets/textures/ на проект.

Проверка: Q-05 · метод: валидатор

## К-09
Проект не принимается без зелёного validate.mjs и REVIEW.md с вердиктом.

Проверка: V-04, V-08 · метод: валидатор

## К-10
Возврат с ворот — точечные правки по пунктам REVIEW, не перезапуск проекта.

Проверка: регламент · метод: арт-директор

## К-11
Удачное из проекта возвращается в архив: приём → references/, скил → skills/, рецепт → motion/.

Проверка: приёмка · метод: куратор

## К-12
Мобильная адаптация — архитектурный принцип: нет горизонтального скролла с 320px, тап-зоны ≥44px, инпуты ≥16px, safe-area учтена.

Проверка: mobile-аудит + sweep 22 вьюпорта · метод: скрипт + арт-директор

## К-13
SEO вшивается до кода: страница не создаётся без page_seo_manifest, JSON-LD по типу и ≥2 внутренних ссылок. Title 50–60, description 120–158.

Проверка: валидатор V-13 + seo-gate · метод: скрипт

## К-14
Дизайн собирается из каталога активов геном-генератором: seed воспроизводим, цветовая гармония вне AI-диапазона 220–260°, комбинация проверяется на уникальность против реестра.

Проверка: геном-станок + реестр отпечатков · метод: скрипт

## К-15
Ошибки ловятся на самом дешёвом слое: IDE → pre-commit → CI → runtime. PR не мержится без зелёного CI, секреты и битые ссылки блокируют гейт.

Проверка: qa fortress + ci-гейты · метод: скрипт

## К-16
Маркетинговая воронка и оффер проектируются до верстки: проект содержит MARKETING.md с UVP, JTBD и картой CTA. Каждая кнопка содержит атрибуты аналитики `data-analytics-event`.

Проверка: lint-marketing.mjs (M-01, M-02) · метод: скрипт

## К-17
Редполитика и чистый копирайтинг: запрещены маркетинговые штампы (B-17) и бессодержательные CTA (B-18). Текст проходит типографирование (неразрывные пробелы, тире, кавычки) без висячих предлогов (B-23).

Проверка: lint-copy.mjs + typographer.mjs · метод: скрипт

## К-18
Продуктовая полнота UX и доступность: все интерактивные компоненты имеют 5 состояний (Ideal, Empty, Loading, Partial, Error). Контрастность текста не ниже 4.5:1 (WCAG AA).

Проверка: A11yContrastValidator + lint-contrast · метод: скрипт

## К-19
Программируемое кодовое видео должно быть детерминированным (Time Virtualization), использовать зарегистрированные рецепты движения (К-05) и поддерживать режим `prefers-reduced-motion`.

Проверка: lint-video-engine.mjs · метод: скрипт
