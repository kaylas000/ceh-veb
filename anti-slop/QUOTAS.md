# QUOTAS — числовые лимиты

| № | Лимит | Что ограничивает |
|---|---|---|
| Q-01 | 1–3 | motion-рецептов на страницу |
| Q-02 | ≤1 | reveal-приёма на секцию |
| Q-03 | ≥1 | асимметричная композиция на страницу |
| Q-04 | ≥8vw | хотя бы один заголовок |
| Q-05 | ≥1 | текстура из assets/textures/ |
| Q-06 | 100% | шрифтов из PAIRS.md |
| Q-07 | ≤2 | акцентных цвета на проект |
| Q-08 | ≥44px | тап-зоны на мобильных (HIG/Material) |
| Q-09 | 1×h1 | один H1 на страницу, title 50–60, description 120–158 |
| Q-10 | ≤1.5MB | вес страницы (gzip) — bundle-бюджет, JS ≤300KB |
| Q-11 | ≥1 | интерактивный инструмент ценности (калькулятор, матрица, фильтр) на проект |
| Q-12 | ≥4.5:1 | коэффициент контрастности текста WCAG 2.1 AA |
| Q-13 | 5 из 5 | обязательных UX-состояний для интерактивных компонентов (Ideal, Empty, Loading, Partial, Error) |
| Q-14 | ≤25 слов | максимальная длина одного предложения в коммерческом тексте (редполитика) |
