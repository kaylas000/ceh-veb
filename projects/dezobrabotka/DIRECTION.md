# DIRECTION.md — PRJ-02 · Дез Обработка (дезинсекция, Пенза)

## Раздача SEED (бросок №4, roulette.mjs от 2026-08-25)

Оси проекта, обязательны к отражению (К-03):

- Композиция: ломаная сетка с левой рейкой
- Движение: маска-reveal строк
- Типографика: капс 9vw, перенос по смыслу

Как оси ложатся: «ломаная сетка с левой рейкой» — постоянная левая рейка-обрез
(вертикальный текст службы, метки актов 01–06) + секции со сдвигом колонок 4/8, 7/5
(SK-02, Q-03). «маска-reveal строк» — основной рецепт показа заголовков и плакатных
строк контактов (ось Движение). «капс 9vw, перенос по смыслу» — постерный h1
и телефон-строка (ось Типографика, Q-04).

## Источники направления

1. `references/archive/REF-06.meta.yaml` — тема дезучёта открывается реестром:
   учётная карточка, строки записей, плотные метаданные вместо витрины;
   прайс — как журнал дезинфекционного учёта, а не «тарифные карточки».
   takeaway: «Архив живёт плотностью записей, а не декором обложки.»
2. `references/editorial/REF-02.meta.yaml` — девять услуг подаются как индекс-реестр
   во всю ширину: имя вредителя крупнее описания, строка раскрывает деталь по ведению,
   а не сетка одинаковых карточек (обход B-04).
   takeaway: «Заменяй сетку карточек плотным индексом: имя проекта крупнее превью.»
3. `references/scroll-story/REF-01.meta.yaml` — протокол обработки (осмотр →
   подготовка → обработка → контроль) — закреплённая сцена, каждый шаг меняет
   ровно одно состояние: номер шага и параметр прибора.
   takeaway: «Закрепи сцену на весь экран и меняй в ней ровно одно состояние на шаг текста.»
4. `references/poster-type/REF-05.meta.yaml` — заголовок работает как плакат:
   капс, перенос строки по смыслу («УНИЧТОЖАЕМ / НАСЕКОМЫХ / И ГРЫЗУНОВ / В ПЕНЗЕ»),
   офсетный бумажный фон без градиентов.
   takeaway: «Набирай заголовок как плакат: размер до 10vw, перенос по смыслу, а не по ширине.»

## Характер движения (1–3 рецепта, Q-01, К-06)

Рецепты-кандидаты (без конфликтов dont_combine_with):
- `motion/recipes/mask-reveal/recipe.yaml` — строки заголовков и телефон-контакт
  выезжают из-под кромки, ceh-brake, 700ms, — ось SEED.
- `motion/recipes/counter-tick/recipe.yaml` — механический пересчёт итога в
  калькуляторе прайса и счётчиков с реальным источником цифры (60 мин выезд,
  21 день контроль, 12 мес гарантия, 50 мкм частица) — ceh-drag, 1200ms.
- `motion/recipes/conveyor-marquee/recipe.yaml` — лента районов Пензы в контактах,
  26s на цикл, ceh-drive, пауза по наведению.

Все easing — только из motion/easing-curves.json (К-05); prefers-reduced-motion
выключает проходы (G3).

Поверх станичного движения (итерация 2, по смотру на мобильном):
- Кинозаставка первого визита (SK-06, пресет intro-assembly): линия загрузки →
  слово собирается из частиц → удар красного штампа → титр → шторки в стороны.
  ≤3.4 с сцены, пропуск с первой секунды и по ESC, один показ за сессию
  (sessionStorage), реплей из футера.
- Живой прибор в hero по SK-05: окно «генератор холодного тумана» — двухслойное
  feTurbulence-облако дрейфует (ceh-coast), LED пульсирует; подпись-метка
  «10–50 мкм · 4-й класс» держит формулярный тон.

## ЧЕМ ЭТО НЕ

- Не «медицинский лендинг с градиентом»: индиго-фиолетовый градиент, градиентный
  текст, стеклянные карточки — приёмы без источника, B-05/B-06/B-07 запрещены;
  у Дез Обработки нет причины выглядеть как стоматология.
- Не «героический центрированный шаблон»: центрированный h1 + подзаголовок +
  две кнопки (B-03) и три одинаковые «услуга-карточки» в ряд (B-04) — сайт
  открывается учётной формой и рейкой, услуги — индексом, а не карточками.
- Не агрессивный «дез-хоррор»: фото паразитов крупным планом и чёрно-жёлтая
  химическая гамма — тема решается плотностью документа (REF-06), а не шоком.
