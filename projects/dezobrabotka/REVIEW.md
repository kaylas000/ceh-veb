## Итерация 2 — смотр на мобильном (2026-08-25, возврат по К-10)

Замечания заказчика с телефона и правки — точечные, без перезапуска проекта:

- Прайс: первая колонка при боковом скролле наслаивалась некорректно —
  `border-collapse: collapse` блокирует sticky-ячейки в мобильных WebKit/Blink.
  Фикс: `border-collapse: separate` + `border-spacing: 0`, непрозрачные фоны
  у sticky-ячеек, сплошные цвета выделения вместо rgba (К-12).
- Протокол: большая sticky-плита накрывала текст шагов.
  Фикс: на ≤900px плита схлопывается в тонкую строку-статус
  (номер + состояние + прогресс), текст читается свободно (К-12).
- «Нет кинематографа»: добавлена заставка SK-06 по пресету intro-assembly
  (линия → частицы → штамп-удар → титр → шторки; ≤3.4 с, пропуск всегда виден,
  ESC, один показ за сессию, реплей из футера, выключена при reduced-motion) —
  рецептов на странице по-прежнему 3, заставка вне страницы, конфликтов
  dont_combine_with нет (К-06, Q-01).
- Живой прибор «генератор холодного тумана» в hero по SK-05: feTurbulence-облако
  дрейфует (ceh-coast), LED пульс — отраслевой артефакт работает на себя (К-04).
- Страховка: скрытие строк reveal теперь работает только при живом JS
  (html.js), без скриптов весь контент виден; якоря не прячутся под планку.
- Кривые по-прежнему только из реестра; новых ключевых слов easing не введено (К-05).
