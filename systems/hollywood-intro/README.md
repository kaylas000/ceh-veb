# Hollywood Intro — кинозаставка

Движок заставки-«титров»: слово собирается из частиц на canvas.

- `IntroEngine.ts` — движок (тот же модуль, что крутит заставку студии в `src/lib/intro.ts`; 577 строк, без зависимостей).
- Готовый vanilla-сниппет с правилами SK-06: `../motion/recipes/intro-assembly/snippet.js`.
- Арт-скил с условиями применения: `../../skills/cinema-intro/SKILL.md`.

## Правила (SK-06)

1. Только студийный сайт или премьерный лендинг — на витринах-каталогах заставки нет.
2. Длительность ≤4с, пропуск обязателен (кнопка + Esc).
3. Раз в сессию: `sessionStorage.setItem("intro-seen","1")`.
4. `prefers-reduced-motion: reduce` — заставка не запускается вообще.
5. Железо-детект: слабые устройства получают сокращённый вариант (меньше частиц, без пост-обработки).
