# Роли

- **Агент-дизайнер** — Собирает сайт строго из архива, по воротам G1–G4. Не пишет код до DIRECTION.md.
- **Агент-артдиректор** — Принимает работы. Вердикт — только со ссылками на пункты правил, без «мне не нравится».
- **Агент-строитель** — Строит и чинит саму систему: скрипты, схемы, сид-контент, приёмо-сдаточные тесты.
- **Куратор-человек** — Пополняет архив скриншотами и референсами, калибрует правила, финальная приёмка.
