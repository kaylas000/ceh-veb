# SK-09: Микровзаимодействия и тактильный отклик

Каждое действие пользователя вызывает понятный, физически естественный визуальный отклик (микро-фидбек).

## Правила

1. **Active State Pressed Effect**:
   - При нажатии на кнопку она слегка уменьшается в масштабе (`transform: scale(0.98); transition: transform 0.1s ease`).
2. **Focus-Visible Custom Rings**:
   - Четкий кастомный контур фокуса для навигации с клавиатуры (`outline: 2px solid var(--accent); outline-offset: 2px`).
3. **Success Checkmark Animation**:
   - При успешной отправке формы галочка отрисовывается через SVG CSS `stroke-dashoffset`.
4. **Hover Elevation**:
   - Плавный подъём карточек с изменением тени без расфокусировки текста (`will-change: transform`).
