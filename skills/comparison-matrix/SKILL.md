# SK-12: Матрица наглядного сравнения

Наглядное демонстрационное сравнение текущего хаотичного способа решения проблемы клиента и системного подхода продукта.

## Структура матрицы

| Критерий | Традиционный подход / Конкуренты | Наше решение (ЦЕХ) |
|---|---|---|
| Сроки поставки | 14-21 день без гарантий | **Точно 3 дня по договору** |
| Точность обработки | ±0.5 мм (требует подгонки) | **±0.01 мм (готов к сборке)** |
| Прозрачность | Скрытые доплаты за логистику | **Фиксированная смета в КП** |

## Правила
- Колонку нашего решения подсвечивать графическим акцентом и галочками.
- Колонку альтернативы оформлять в приглушенных тонах.
