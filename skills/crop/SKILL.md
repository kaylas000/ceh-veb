# Редакционная обрезка фото (SK-04)

## Правила
1. Кадрировать по действию, не по композиции исходника
2. Обрезать смело: до 60% кадра могут уйти
3. Чёрно-белый дубль, если цвет спорит с палитрой
4. Подпись — mono, в поле, с координатами или источником
5. Никаких рамок-скруглений (B-10)

## Пример
Рука оператора на пульте, обрезана по локоть; подпись mono в поле слева.

## Частые ошибки
- Кадрирование «с запасом воздуха»
- Скругления углов (B-10)
- Рамки с тенью
