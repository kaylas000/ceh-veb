# SKILL-INDEX

- SK-01 **Плакатная типографика** — Заголовок должен работать как изображение: афиши, манифесты, первые экраны.
- SK-02 **Ломаная сетка** — Страница длиннее трёх секций: нужна асимметрия без хаоса (Q-03).
- SK-03 **Скролл-сторителлинг** — Нарратив из ≥5 шагов: процесс, ворота, данные, регламент.
- SK-04 **Редакционная обрезка фото** — Фото без арт-дирекшна: сток, скриншоты, фото клиента.
- SK-05 **Производственный паспорт** — Промышленная/ремесленная тема: открыть сайт её характерным артефактом, а не hero.
- SK-06 **Кинозаставка (intro)** — Сайт студии или премьерный лендинг: нужен эффект «титров» перед контентом.
