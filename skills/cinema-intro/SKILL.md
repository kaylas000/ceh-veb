# Кинозаставка (intro) (SK-06)

## Правила
1. Длительность ≤4 секунд; кнопка «Пропустить» видна с первой секунды, ESC тоже работает
2. Один показ за сессию: sessionStorage + явный реплей из шапки
3. prefers-reduced-motion — заставка не показывается вообще
4. Таймлайн один: загрузка → сцена → титр → шторки к сайту; никаких параллельных анимаций
5. Звук — синтез Web Audio, только после жеста пользователя, без внешних файлов
6. Пресеты регистрируются в motion/recipes и меняются по кругу при реплее

## Пример
Заставка ЦЕХа: частицы собирают слово из хаоса, удар, титр, кино-шторки открывают паспорт.

## Частые ошибки
- Заставка при каждом открытии страницы
- Автозвук без жеста
- Дольше 4 секунд без skip
