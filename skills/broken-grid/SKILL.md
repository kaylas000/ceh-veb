# Ломаная сетка (SK-02)

## Правила
1. База — 12 колонок; каждая секция ломает не больше двух
2. Левая рейка-индекс сквозная, контент дышит справа
3. Сдвиг по вертикали ≥ 4vh между соседними блоками
4. Пустое поле — элемент композиции, не «недоделка»
5. Ломается сетка, а не выравнивание текста внутри блока

## Пример
Табличка проекта на 7 колонок слева, индекс сдвинут в поле на 9-й.

## Частые ошибки
- Ломать каждую секцию (шум)
- Сдвиг ради сдвига без причины
- Центрирование после ломки (B-03)
