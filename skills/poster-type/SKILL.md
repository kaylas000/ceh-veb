# Плакатная типографика (SK-01)

## Правила
1. Один уровень иерархии на экран: гигант + техподпись
2. Размер от 8vw (Q-04), строки ломаются по смыслу
3. Кернинг плотный, интерлиньяж 0.9–0.95
4. Не больше двух гарнитур: display + mono-подписи
5. Акцент — одно слово цветом или обводкой, не градиентом

## Пример
«ЦЕХ / НЕ ПРОЩАЕТ / ОШИБОК» — три строки, перенос по смыслу, красная средняя строка.

## Частые ошибки
- Перенос по ширине контейнера
- Три и более размера в одном экране
- Градиентная заливка (B-06)
