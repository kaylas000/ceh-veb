# Производственный паспорт (SK-05)

## Правила
1. Первый экран — документ профессии: наряд, паспорт, накладная, пульт (обход B-03)
2. Живой прибор вместо слайдера: печь, станок, таймер цикла — с телеметрией
3. Фирменный акцент — из рабочей палитры отрасли (RAL, Pantone), не градиент
4. Цифры — mono, с единицами измерения, как на шильдике
5. Один сквозной параметр (цвет/температура) связывает hero, калькулятор и галерею

## Пример
Наряд-заказ № + печь 200 °C с таймером; выбранный RAL красит конвейер и кнопку расчёта.

## Частые ошибки
- «Современный» hero с градиентом (B-05)
- Прибор без цифр — просто картинка
- Акцент, не связанный с отраслью
