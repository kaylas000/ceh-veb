# SK-08: Интерактивные таблицы и матрицы данных

Таблицы характеристик, цен и параметров часто ломаются на мобильных экранах. Этот скил задает правила адаптивной трансформации таблиц.

## Правила построения

1. **Sticky Header & Fixed Column**:
   - Первая колонка (наименование параметра) закрепляется слева при горизонтальном скролле на мобильных устройствах (`position: sticky; left: 0`).
2. **Card-View Transformation**:
   - На экранах < 640px таблица трансформируется из многоколоночной сетки в набор вертикальных карточек с повторяющимися метками (`data-label`).
3. **Подсветка различий (Diff Highlight)**:
   - Переключатель «Только различия», скрывающий совпадающие строковые значения.

## Пример CSS для безопасного скролла:
```css
.table-container {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  border: 1px solid var(--border-color);
}
.table-container th:first-child,
.table-container td:first-child {
  position: sticky;
  left: 0;
  background: var(--bg-surface);
  z-index: 2;
}
```
