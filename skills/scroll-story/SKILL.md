# Скролл-сторителлинг (SK-03)

## Правила
1. Одна сцена — одно состояние; шаг текста меняет ровно одно
2. Сцена закреплена (sticky), текст прокручивается
3. Активный шаг подсвечивается, прошлые гаснут до 25%
4. Между шагами — воздух ≥40vh
5. Финал — артефакт (штамп, цифра, вердикт), не кнопка

## Пример
Ворота G1–G4: закреплённая плита меняет номер и чек-лист по шагам.

## Частые ошибки
- Пять анимаций на шаг
- Сцена без закрепа (плывёт)
- Текст мельче 16px на шаге
