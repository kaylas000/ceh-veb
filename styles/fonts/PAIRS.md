# PAIRS — шрифтовые пары с ролями

Шрифты вне пар запрещены (Q-06).

1. Russo One + Golos Text — заводская табличка. Капс-штампы и индексы; Golos держит длинный набор.
2. Unbounded + PT Sans — широкий плакат. Unbounded для одного слова-гиганта, PT Sans — рабочая лошадка.
3. Yeseva One + Jost — редакционный контраст. Антиква в заголовках против геометричного набора.
4. Tektur + IBM Plex Sans — приборная панель. Технический дисплей + Plex для данных и подписей.
5. Cormorant Garamond + Rubik — архивная опись. Курсивная антиква в заголовках описей; Rubik — подписи и таблицы.
